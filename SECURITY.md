# Security Policy

## Security Overview

The **Playwright Engineering Handbook** repository is an educational and reference project that contains example Playwright automation frameworks, sample applications, CI/CD configurations, and AI-assisted browser automation demonstrations.

Although this repository is intended primarily for learning purposes, security remains an important priority.

If you discover a security vulnerability within this repository, please report it responsibly rather than disclosing it publicly.

---

# Supported Versions

The latest version of the repository is actively maintained.

| Version              | Supported     |
| -------------------- | ------------- |
| Latest (main branch) | ✅ Yes         |
| Previous releases    | ⚠ Best effort |
| Archived versions    | ❌ No          |

We recommend always using the latest version of the repository.

---

# Reporting a Security Vulnerability

If you discover a security issue, please **do not create a public GitHub Issue**.

Instead, report the vulnerability privately.

### Contact

**Email**

[parthkandpal.qa@gmail.com](mailto:parthkandpal.qa@gmail.com)

When reporting a vulnerability, please include:

* Description of the issue
* Steps to reproduce
* Potential impact
* Suggested remediation (if available)
* Screenshots or logs (if applicable)

Reports containing clear reproduction steps help us investigate more efficiently.

---

# Response Process

After receiving a security report, the following process will generally be followed:

1. Acknowledge receipt of the report.
2. Investigate the reported issue.
3. Assess the severity and impact.
4. Develop and test a fix if necessary.
5. Publish the fix in the repository.
6. Credit the reporter when appropriate (unless anonymity is requested).

Response times may vary depending on the complexity of the issue.

---

# Scope

This policy applies to:

* Example Playwright automation code
* Framework implementations
* CI/CD pipeline examples
* Configuration files
* Documentation
* Playwright MCP examples
* Repository scripts

---

# Out of Scope

The following are generally considered outside the scope of this repository:

* Security issues in third-party software (Playwright, Node.js, TypeScript, GitHub, etc.)
* Vulnerabilities within external libraries
* Vulnerabilities in user environments
* Misconfigured local development machines
* Denial-of-service attacks against GitHub infrastructure
* Social engineering attempts

Please report issues affecting third-party software directly to the respective maintainers.

---

# Dependency Security

This repository relies on external open-source packages.

We recommend:

* Keeping dependencies updated.
* Regularly reviewing dependency advisories.
* Running dependency audits before production use.
* Monitoring official Playwright release notes.

Useful commands include:

```bash
npm audit
```

```bash
npm audit fix
```

---

# Responsible Disclosure

We appreciate responsible disclosure practices.

Please allow reasonable time to investigate and resolve reported issues before publicly discussing them.

Working together helps improve the security of the project while protecting users.

---

# Educational Disclaimer

The code and examples provided in this repository are intended for educational and demonstration purposes.

Before using any example in a production environment, it should undergo:

* Security review
* Code review
* Testing
* Validation
* Compliance checks

Production deployments should always follow your organization's security standards and governance policies.
