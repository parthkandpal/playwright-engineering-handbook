# Support

Thank you for your interest in **The Playwright Engineering Handbook** and its companion repository.

This project is intended to help software engineers, Quality Engineers, SDETs, automation architects, and students learn modern Playwright automation, enterprise framework design, and AI-assisted browser automation.

If you need assistance, this document explains the best ways to get help.

---

# Before Asking for Help

Please check the following resources first:

* The book chapters
* The repository documentation
* The Appendix Cheat Sheets
* Existing GitHub Issues
* Existing GitHub Discussions (if enabled)
* Official Playwright Documentation

Many common questions are already answered in these resources.

---

# Getting Help

## GitHub Issues

Use GitHub Issues for:

* Bugs
* Broken examples
* Documentation errors
* Repository problems
* Incorrect code samples

When creating an issue, please include:

* Clear description
* Expected behavior
* Actual behavior
* Steps to reproduce
* Playwright version
* Node.js version
* Operating system
* Screenshots (if applicable)

---

## Feature Requests

Suggestions are always welcome.

Examples include:

* New Playwright examples
* Additional MCP demonstrations
* Enterprise framework improvements
* CI/CD templates
* New interview questions
* Additional cheat sheets

Please explain the problem your suggestion solves.

---

## Documentation Improvements

If you notice:

* Typographical errors
* Incorrect explanations
* Outdated information
* Missing examples

please open an Issue or submit a Pull Request.

Documentation contributions are greatly appreciated.

---

## Playwright Questions

Questions related to:

* Locators
* Assertions
* Fixtures
* POM
* TypeScript
* Playwright MCP
* Enterprise framework architecture

are welcome.

Before opening an issue, please verify that the topic is not already covered in the book or repository.
