# Upgrade Notes

Whenever upgrading to a newer release:

1. Review this changelog.
2. Update project dependencies.
3. Reinstall Playwright browsers if necessary.
4. Review breaking changes.
5. Execute the complete test suite before production use.

# Reporting Issues

If you discover an issue introduced in a release, please create a GitHub Issue with:

* Repository version
* Playwright version
* Node.js version
* Operating system
* Steps to reproduce
* Expected behavior
* Actual behavior
