# Getting Started

Clone the repository:

```bash
git clone https://github.com/parthkandpal/playwright-engineering-handbook.git
```

Navigate to the project:

```bash
cd playwright-engineering-handbook
```

Install dependencies:

```bash
npm install
```

Install Playwright browsers:

```bash
npx playwright install
```

Run all tests:

```bash
npx playwright test
```

Launch UI Mode:

```bash
npx playwright test --ui
```

Open the HTML report:

```bash
npx playwright show-report
```
